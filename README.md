Deskripsi Program Kasir Sederhana
//Program kasir sederhana ini merupakan aplikasi berbasis bahasa pemrograman C++ yang dirancang untuk mensimulasikan proses transaksi penjualan pada sebuah toko. Program ini memungkinkan pengguna untuk memilih beberapa jenis barang yang tersedia pada menu, menentukan jumlah barang yang ingin dibeli, menghitung total harga pembelian, memberikan diskon berdasarkan jumlah transaksi, serta menghitung kembalian dari pembayaran yang dilakukan pelanggan.

Pada program ini, pengguna akan diberikan daftar produk beserta harga masing-masing. Setelah memilih barang yang diinginkan dan memasukkan jumlah pembelian, program secara otomatis menghitung subtotal setiap barang dan menambahkannya ke dalam total belanja. Proses pemilihan barang dilakukan secara berulang menggunakan struktur perulangan sehingga pengguna dapat membeli lebih dari satu jenis barang dalam satu transaksi.

Selain itu, program menerapkan konsep percabangan untuk menentukan besarnya diskon yang diperoleh pelanggan. Diskon diberikan berdasarkan total nilai transaksi, yaitu semakin besar total pembelian maka semakin besar pula persentase diskon yang diterima. Setelah diskon dihitung, program akan menampilkan total pembayaran yang harus dibayarkan oleh pelanggan.

Pada tahap akhir, pengguna diminta memasukkan jumlah uang yang digunakan untuk membayar. Program kemudian menghitung selisih antara jumlah pembayaran dan total tagihan setelah diskon untuk menentukan besarnya uang kembalian yang diterima pelanggan.

Dari sisi pemrograman, program ini mengimplementasikan beberapa konsep dasar bahasa C++, seperti penggunaan variabel, tipe data, input dan output (cin dan cout), percabangan (if-else), pemilihan (switch-case), serta perulangan (do-while). Dengan demikian, program ini dapat dijadikan sebagai contoh penerapan dasar-dasar pemrograman dalam pembuatan sistem kasir sederhana yang mampu melakukan proses transaksi secara otomatis dan terstruktur.
